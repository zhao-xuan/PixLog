# Demo Source Images

PixLog's recordings use two real source images. The binaries are vendored so
demo setup and recording remain deterministic and offline.

## Earthrise

- File: `earthrise.jpg`
- Work: *Earthrise*, photographed by NASA astronaut Bill Anders during Apollo 8
  on 24 December 1968.
- Source: <https://commons.wikimedia.org/wiki/File:NASA-Apollo8-Dec24-Earthrise.jpg>
- License: Public domain in the United States as a work created by NASA.
- SHA-256: `24fd2a4f833534ca6741ed96d03b028ac1d8fda2cd129ded4d208535f541d4da`

## Stable Diffusion 3.5 Output

- File: `stable-diffusion-3.5-astronaut.webp`
- Work: *Astronaut Riding a Horse (SD3.5)*, generated by Wikimedia Commons user
  VulcanSphere with Stable Diffusion 3.5 Large in a Hugging Face Space.
- Prompt: `a photograph of an astronaut riding a horse`
- Source: <https://commons.wikimedia.org/wiki/File:Astronaut_Riding_a_Horse_(SD3.5).webp>
- License: Public domain; the Commons file is also categorized as CC0.
- SHA-256: `0426c90afa64550e939e9f93403f2ed1e04bc52de55f12bb9b82a0a53cd8b1fd`

Run `scripts/marketing/update-source-assets.sh` to download both files and
verify their checksums before replacing the vendored copies.
