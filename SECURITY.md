# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older
releases may require upgrading to receive a fix.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/zhao-xuan/PixLog/security/advisories/new).
Do not open a public issue before a fix or mitigation is available.

Include the affected PixLog version, operating system, reproduction steps,
security impact, and any known mitigations. Remove credentials, private media,
and other sensitive data from reports and reproductions.
